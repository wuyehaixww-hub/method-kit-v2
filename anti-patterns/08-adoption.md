# L3 反例 · 08 采纳（A-18）

> 反例 = **真实发生过的失效**，带实测数字 + 日期 + 出处。选条标准：**每个不同根因各一条**（`P-21` 替换测试）。
> 每条四段：**现象** / **根因** / **正解（指向 P-NN）** / **怎么早发现**。

## A-18 采纳记录写了「明天就没了」的位置

- **现象**（2026-11-01，一次真实接入，干净样本）：执行者把 `…\Temp\…` 这个**临时目录**写进了验收清单 §5 与状态行的「顾虑」段；而**同一份记录里它自己已经分析过**「Temp 会被清理，长期引用前先搬家」——自己写下的理由，没有用在自己的记录上。
- **根因**：把「我当时在哪看到的」当成了「来源」。位置有两种 —— **稳定位置**（进版本库 / 有 ID / 明天还在）与**临时位置**（本机 Temp / 会被清理的副本 / 绝对路径）。字段名叫「来源」，但**没有任何判据规定哪种来源合格**。
- **正解**：P-29（只写明天打得开的，否则写「未落地」）。
- **怎么早发现**：看到路径先问一句「三个月后它还打得开吗」；出现 `Temp` / `%TEMP%` / `AppData` / 盘符绝对路径 → 立刻判不合格，改成「未落地」或换成稳定出处。
