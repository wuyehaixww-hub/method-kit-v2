# L0 原则 · 07 反例（同型 / 准入 / 转正 / 取证 / 摘要）

> 本册 = 「**一条失效凭什么进反例库，进去以后凭什么一直成立**」。5 条：P-21..P-25。
> **阈值不写在本册**（真源 = `kit.config.json`）；**动作清单也不写在本册**（跑什么 / 什么时候跑：发布件按 `kit/templates/CLOSEOUT.md.template` 自建；维护者仓见 `WORKFLOW.md` §收尾）。本册只写判据。
> 与邻近册的分工：**怎么用反例做复核** = 02 册（P-10 ②：只找反例、换判据）+ 03 册（P-19 独立复跑 / P-20 复核边界）；**怎么找失效** = 05 册（P-02 回退阶梯）；**门禁能覆盖哪一类** = 04 册（P-15）。**本册 = 失效样本本身**：算不算新、立不立、有没有转正、拿什么当证据、它的摘要跟不跟得上。
> 每条四段：**规则** / **为什么** / **反例** / **怎么查**；`怎么查` 按真实面写 —— **完全没门禁写「无机械点」**，只有间接 / 部分覆盖才写「半机械」，**别认领一个不管这件事的探针**。
> 册内数量口径：**每个不同根因各一条**（本册 3 条；`anti-patterns/04-gates.md` 现 4 条 = 4 个根因）；「不同」怎么判 = P-21（不是自评）。

## P-21 两条反例算不算「不同」：用替换测试判，不看标题


- **规则**：立新条前做两个测试。**替换测试**：把已有反例的「根因」第一句抽出来，逐条问「我这条的根因句**能不能替换掉它而不失真**？」——能替换 = **同一条**，不许立。**唯一性测试**：「我这条现象，**换一个根因能不能也讲通**？」能 = 它是别条的实例，不是新条。撞上之后只许三种处置：**换根因**（你抓到的确实是另一种失效）/ **降为实例**（并进已有条的现象段，作为它的第 N 个实例）/ **降为证据行**（降为某条判据的实例，不再单独立条）。三种处置都只作用于**新条**；旧条只在**它自己也被证明错**时才当轮改 —— 那是「改反例」不是「加反例」，汇报里单列。**册首的「三个不同根因」是数量口径；本条给的是「不同」的判据** —— 没有这一条，「不同」只是自评。
- **为什么**：反例册的浓度 = **不同根因的条数**，不是条目数。作者判重复时看得见的是**标题**，而根因是正文里那句结构解释 —— 「标题不同、根因相同」是最自然的一次误判（本方法仓实测：A-10 首版整条就是 A-06 的同义改写，而两条的标题完全不同）。失败也不报错：两条都读得通，读者会把同一件事读成两个形态（A-14）。
- **反例**：A-14。
- **怎么查**：**半机械** —— 没有探针能判「两条的根因是不是一回事」（语义）。机械辅助：把已有条的「根因」段第一句 `grep` 出来做成一行清单（条数 = `grep -c '^## A-' anti-patterns/*.md` 的和，或 pwsh `Select-String -Pattern '^## A-' anti-patterns\*.md`；不写死在文里 —— 写死的条数会漂，P-25），人工逐行做替换测试。**与 P-05 的分工**：配额管「条数到顶先退役」；本条管「新条凭什么算新」。

## P-22 准入：四种东西不进 L3（① 回家，② 进 `inbox/`，③④ 先去打开原件）


- **规则**：四种东西**不进 L3**：① **完成记录 / 里程碑**（「某棒做完了」不是失效）；② **无出处的经验**（没有日期、没有可指到的处的「据说」）；③ **别人正在改的正文**（原件可能被订正 → 见 P-24）；④ **转述**（我没在本会话打开过的东西 —— 「本会话」= 当前这个 agent 会话里你**亲眼读到**的原文或命令输出；子 agent / 上一棒读到的都算转述，要它把原文贴回来才算）。① **不进 `inbox/`**：完成记录有自己的家（当前状态行 / 过程账）—— 它不会靠「等」长出出处，放进暂存区只会多一次搬运；② 先进 `inbox/`（**本方法仓目录** = `inbox/`；配额门在目录存在时才判，`P-05`），等它长出「日期 + 可指到的处」再转正；③④不立条，先去打开原件。另加一道**唯一性前置**：立条前先查同类（走 P-21）。**入口分工（与 P-23）**：`inbox/` 收的是**材料还不够格**的（缺日期 / 缺出处）；材料够格但**没有可指的 P** = 已经立条、**待转正**，走 P-23 的登记面 —— 两个入口不重叠。
- **为什么**：反例的价值全在「它真的发生过，而且我能带你去看」。放进一条完成记录，读者会把它当失效形态去防；放进一条传说，读者学到的是作者的语气而不是事实。而**稀释不可逆**：条目一旦立起来，很少有人回头问「这条到底算不算」——反例册就这样长成一本流水账。
- **反例**：A-11（把上一棒的转述当事实写进交接件 —— 同一次「没打开就下笔」，换个载体就是本条）。
- **怎么查**：**无机械点（纯人工）** —— 探针 12 的 A 侧只管「指得回判据 + 有「怎么早发现」」，那是 P-23 的门，判不了准入的四类。人工三问：**我在本会话打开过那段原文吗 / 它有日期吗 / 同类已经有了吗**（第三问走 P-21）。**与 P-07 ⑤ 的分工**：那条管「还没做的事」进留后登记面；本条管「已经发生的事」够不够格当样本。**与 P-17 的分工**：P-17 管**写进交接件的断言**（每句都要指得回原件或给判据）；本条管**写进 L3 的材料**（每段失效都要本会话打开过）—— 判据同源（A-11）、载体不同。

## P-23 转正：反例的「正解」是判据指针，不是规则复制


- **规则**：每条反例的「正解」段 = **`P-NN` 指针 + 一句能执行的动作 + 一句分工**（这条 A 是**那条** P 的病，不是别的 P 的病）。**禁**把 P 的规则句抄进 A：同一句规则写两处 = 第二个书写点，改一处必漏（A-06）。**没有可指的 P** = 这条失效还没被固化成规则 → 标「**待转正**」并进唯一登记面（本方法仓 = 台账 §5），**不许留空的正解段**。已转正的条目**保留**（它是判据的负样本），不因「已经有规则了」而删。本方法仓的「转正」以**正解指针**表达（探针 12 机械判），**不在标题加【转正：见 …】标记** —— 那会让同一件事多一个书写点（上游项目的标记法是在它自己没有指针门禁时才需要）。
- **为什么**：反例是**证据**，规则是**判据** —— 两层混写会同时坏掉两边：A 里有了规则句，读者读 A 就够了，不会再去读 P（P 的分工句、怎么查就此没人看）；而 A 一旦被当成「规则的第二份」，它就开始跟着规则一起漂。「待转正」这个标记则是唯一能让「立了反例但没立规则」**可见**的东西 —— 否则它只会躺在册子里，谁也不知道它还没生效。
- **反例**：A-06（同一件事写两处 → 只改被看见的那处；把规则抄进 A 就是再造一个书写点）。
- **怎么查**：**半机械** —— 机械点 = 探针 12 的 A 侧（`node kit/scripts/check-kit.mjs`：每条 `## A-NN` 必须含 ≥1 个 `P-NN`），**它只判「指了没有」，判不了「指对没有 / 有没有抄规则」**（后者属 P-15 的不可机械类）。人工：读 A 的「正解」段，问「这句话在对应的 P 里是不是已经有一份**逐字**的？」——是 → 删掉，改成指针 + 分工。

## P-24 取证：只引「明天还打得开」的形态


- **规则**：反例的证据只引**四种东西**：① **编号**（`A-10` / `R-6`）；② **记录**（复盘记录 / 决策书 / 门禁尾行）；③ **节标题**（或「节号 + 记录内的局部编号」，如 `§8.2 R-2` —— 节号随提交漂、比行号稳，但**单靠节号会串节**：有一次自审就把两处 R-5 都写成同一节，逐行核对才发现一处属 §8.2、一处属 §8.3）；④ **命令输出**（贴尾行）。**不引「当时那句话」**：确需引原文，必须同时写 ①「**原件可能已被订正**」的风险位 ② `复核月`。`复核月` = **你最后一次打开出处核对的那个月**（`YYYY-MM`；新写 = 写下时的月，重读后 = 重读的月）。跨机可解析性 = `P-18` ③（本条不复述）。
- **为什么**：证据底座如果是**活正文**，它就带着一个有效期，而条目本身不报错 —— 今天读得通，明天复核者找不到那句话。更贵的是**误判方向**：复核者找不到时，第一反应是「我是不是找错了文件」，而不是「这条引文早失效了」（本方法仓实测：A-11 ② 的引文随原件订正、当天就消失）。所以取证要选**最难被改掉**的形态，不是**最像原话**的形态。
- **反例**：A-15。
- **怎么查**：**半机械（覆盖分层）** —— ① 本方法仓 `.md` 路径存在（探针 5）+ 编号存在（探针 2）；② 跨仓指针只在你自己的仓里才需要（本包不带跨仓指针，也不带那套体检脚本）；③ **引文还在不在、数字还对不对** = 没有任何探针 —— 只能人工问「**下个月还有谁能打开它**」，引里的数字当场数一遍（P-10 ①）。**与 P-10 ① 的分工**：那条管「这个数是不是命令输出」；本条管「这个证据载体本身会不会消失」。

## P-25 摘要不是副本：改正文就欠摘要一次回改


- **规则**：下列位置**都在替正文说话**，因此都是**书写点**：文件标题 / 引言首句 / 表格表头 / 索引行 / 地图行 / 册首的条目区间。**改正文 = 欠一次回改**：同一轮里要么改摘要，要么把它**降级成纯指针**（只写位置与角色，不写口径、不写数字、不写范围）。能生成的就别手写（索引 / 地图配双向校验）。摘要里的**数字与范围**（`R1–R14` / `3 条` / `19 行`）是漂移高发区：写之前数一遍。
- **为什么**：**摘要不是副本** —— 副本按定义应与原件逐字相等（A-06 治的是它），摘要是**有损导数**：它在写入那一刻被压缩，之后原件改了什么它都不知道。而它站在读者**先读到**的位置（标题 → 表头 → 地图行 → 正文），所以它错的时候不只是「没更新」，是**先入为主**：读者拿着旧口径去读新正文，甚至反过来怀疑正文。这类失效没有机械签名（P-15 已点名它属「不可机械」那一类），只能靠一条**单向义务**接住（A-13）。
- **反例**：A-13。
- **怎么查**：**无机械点** —— 探针 1 只判**地图行 ID 集合**与定义双向相等，**判不了地图行的措辞**（一次实测：`README.md` 的 P-22 行一度与条文相反，`check-kit` 仍 0 FAIL，记在一条复盘记录里（§4 R14））；「标题 / 表头 / 索引行有没有说旧口径」只能人工回读。人工：改完正文，回读该文件的**摘要位**（上列六处一一过），逐句问「这句是不是在替正文说话」；是 → 同改或降级为指针。**与 P-06 / P-09 的分工**：P-06 问「同一事实有没有两处写全」（副本 / 单一书写）；P-09 的四类反查面是**名字 / 路径 / 节号 / 状态词 / 数字**，**不含摘要句的口径**；P-15 只说这类失效归「固定时点问句」，没给义务 —— 本条给的是**义务 + 时点**（改正文的同一轮）。
