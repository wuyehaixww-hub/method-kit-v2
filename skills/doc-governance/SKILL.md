# doc-governance · 文档体量与增长治理

> 一句话：**先量读上限，再逐份盘点，再按 `P-32` 的四问决定拆不拆**；处置顺序固定，用户拍板。
> 判据不在这里写全：读 / 容量 = `P-03` / `P-04` / `P-05` / `P-30`；拆卷 = `P-32`；写入即分流 = `P-08`。本件只给步骤与输出格式。

## 何时用

- 项目文档在长；单份文件「一次读不完」或不敢整读；有人问「我的文档是不是太大了」。
- 想拆卷 / 建路由页 / 建索引；或新项目要预防文档失控。

## 何时不用

- 只想量冷启动字节 → `cold-start-size`。
- 想判「这套方法适不适合我」→ `fit-kit`。
- 想改判据 → 不是本件（判据在 `principles/`）。

## 硬纪律（六条）

1. **用户决定权**：「不拆」是合格答案；本件只给选项与依据。
2. **不盲目压缩**：先按节读；撞**册上限**才按 抬阈值 > 拆 > 退役；撞**读上限**不抬阈值（见 §4）。
3. **阈值只写 `kit.config.json`**；本件不写死字节。
4. **判据只引 `P-NN`**，不抄正文。
5. **只读用户仓**（记录除外）；测量临时文件可造在**仓外**，用完删；不跑用户门禁、不装、不取。
6. **点名被量对象**（`P-27`）：体检单第一行写目标仓；量错对象 = 没验收。

## 七步

### 0 定位

- 目标仓是哪一个（**不是方法包自己**）；有文档 → 步骤 1；**绿地**（没文档）→ 跳步骤 6。

### 1 测读上限（三项都要）

- 造一个**已知大小**的临时文件（放**仓外**临时目录、用完删；示例起点约 40 KiB / 1,500 行；**没截断就加倍、截断就减半**，二分到边界），用**你自己的读工具**读；比较「返回的字节 / 行数 / 最后一行」与文件实际。
- 三项分别测：**字节上限** · **行数上限** · **单行字符上限**。
- 截断判据：返回行数 < 文件总行数，或最后一行 ≠ 文件最后一行 = 截断；工具明说 truncated 也记，但**以实测为准**。**别靠页脚** —— 脚本里调读工具常常没有页脚。
- 记录：harness / 模型 / 日期 / 三个数 / 检测方式 → 冷启动三件里的**当前状态件**（没有就记进本次体检单）。

### 2 盘点（只列不读）

- 规则文档（`.md` / `.txt` / `.rst`）：份数 + **逐文件字节 / 行数 / 最长行**；排除 `.git` / `node_modules` / `vendor` / `dist` / `build` 与生成物。
- 按「会整读吗」分 `P-03` 四档（A 整读 / B 按需 / C 索引 / D 抽屉）；判不准取更严的一档。

### 3 风险分级

- **红** = 字节 / 行数超实测上限，**或最长行 > 单行字符上限**；**黄** = 未超限但已接近（比例由用户定，写进本次体检单，不写死）；**绿** = 其余。
- 红 / 黄再分：**已声明按节读**（`P-04`，可接受、记录）/ **未声明**（优先处置）。**单行超限不因「按节读」豁免**（按节读也会读那一行）—— 必须拆行。

### 4 处置（按 `P-32` 四问，按序）

- **打开 `P-32` 正文**，按它的四个问题逐条走（题面与五条硬约束在 `P-32`，本件不复述）。
- 每个红 / 黄文件必须落到一个动作：**按节读 / 抬阈值（只对册上限）/ 拆 / 归档 / 退役**，并写「依据 = `P-32` 第 N 问」。
- **降级顺序分两个触发**：撞**读上限**（实测）= 按节读 > 拆 / 归档（读上限不可抬）；撞**册上限**（`kit.config.json` 的 `perVolumeLimitBytes`）= 按节读 > 抬阈值 > 拆（只按读者）> 退役。

### 5 增长类型表 + 触发

| 文档类型 | 默认控制 | 触发（提前写） | 阈值指针 |
|---|---|---|---|
| 台账 / 进度 | 配额（`P-05`）+ 收口归档 | 撞配额 / 撞上限 | `quotas` · `capacityTiers` |
| 变更日志 | 只追加最新段 + 归档旧段 | 撞硬顶（WARN 只提醒，不是触发） | `capacityTiers.readyThrough` |
| 坑索引 / 决策记录 | 一条目一行 + 索引生成 | 撞上限 / 索引漂移 | `capacityTiers` |
| 会话记录 / 历史 | 写入即分流（`P-08`）+ 归档 | 棒收口 / 撞门 | `capacityTiers.tiersByDir` |
| 索引页 / 路由页 | **生成**（`read-plan` 现抽），不手写 | 路由页 > 中位数 | —— |
| 冷启动三件 | 字节门 + 强制归档（`P-01`） | 余量 < 强制线 | `coldStart` |

- 阈值只写指针；**触发必须提前写** —— 撞线那天再来定，通常只剩「拆」或「破线」两条路。

### 6 绿地（没有文档 / 新项目）

- **三问**：哪些文档会长期长？谁会整读它？什么信号出现时再来？
- **预写约定**：节号稳定（标题即索引）· 索引生成（`read-plan` 现抽，不手写）· 历史件默认按节读 · 写入即分流（`P-08`）· 给增长型文档先设配额（`P-05`）。

### 7 防腐

- 路由页 ≤ 中位数；索引由生成或过期自检（`P-14`）；拆是单向门（`P-32`）；每次拆后问「为哪类读者少读了？」；**冷启动面永不拆**。

## 输出：体量体检单（≤20 行）

```
日期 · 目标仓 · 方法包
读上限实测：字节 N / 行数 N / 单行 N（harness · 模型 · 日期）
红：<文件> <字节>/<行> → <动作 + 依据（P-32 第 N 问）>
黄：…
绿地三问 / 用户待裁：…
复审：日期或触发
```

## 记录

- 默认写一份（上面格式）；路径三级：`session-notes/` → `docs/` → 仓根 `doc-governance-<日期>.md`（都没有就落根并说明）。
- **同场已按 `fit-kit` 写过记录** → 把体检单并入同一份，不另起文件。
- 用户说「别写」→ 不写，对话里给结论并标「未落盘」。

## 不做

- 不装 / 不取 / 不改用户仓（记录除外）；不跑用户门禁；不手写索引；不立判据；不做脚本。
