# L0 原则 · 03 交接（外置 / 原件 / 证伪 / 复跑 / 边界）

> 本册 = 「**一次交接凭什么能让下一棒直接开工**」。5 条：P-16..P-20。
> **阈值不写在本册**（真源 = `kit.config.json`）；**动作清单也不写在本册**（跑什么、什么时候跑：按 `kit/templates/CLOSEOUT.md.template` 自建）。本册只写**判据**。
> 与邻近册的分工：**收尾** = 02 册（P-06..P-10：真源闭合 / 反查 / 可证伪）；**取料** = 05 册（P-01..P-05：冷启动面 / 回退阶梯）；**门禁** = 04 册（P-11..P-15：门禁的结论怎么读）。**本册 = 交接件自身**：交给谁、写什么、读完算什么。
> 每条四段：**规则** / **为什么** / **反例** / **怎么查**；`怎么查` 没有机械点就诚实写「半机械」，不假装有门禁。

## P-16 交接件只写「本棒差异」；稳定层只写一处


- **规则**：每棒重写的那一件（handoff）只写**本棒才有的内容** —— 最小集 = 快照（**写法**受 P-17 管）/ 一句话任务 + 边界 / 必读清单（受 P-18 管）/ 下一步与未做项的**指针**；**骨架字段以 L1 模板为准**（模板可加「顾虑」「收尾同步记录」等字段，本条不封口；**模板尚未建时按上面的最小集写**）。**角色 / 验收命令 / 环境速查 / 机械检查清单 / 阈值**属稳定层：**只在一处写全**，交接件里只留指针。**边界一格**：「跑**哪条**命令」是稳定层（指针）；「**这次**跑出来的结果」（门禁基线 / 字节 / 条数）是本棒快照（命令 + 实测时间），不是稳定层。**指针化成立的前提 = 指针落得到唯一实体**（跨件引用写名字或全局 ID —— 见 A-10；落错物比留副本更贵）。**本方法仓若还没有稳定层件**（角色 / 命令 / 环境没有唯一落点），则先把它抽出去（一次成本），不是每棒再抄一遍 —— 抄第 N 遍时它已经是副本了。（**与 P-06 的分工**：P-06 问「收尾时真源改没改」，本条问「这段该不该出现在本棒这一件里」。）
- **为什么**：交接件是**每棒新写一份**的东西 —— 复制一次就多一个副本，而副本**不报错**：复制的那一刻它是对的，之后没有任何「我过期了」的信号；改规则的人只会改他正在读的那一处，另一份从此是「上一版的正确」。两份口径**都读得通**，只有照着做的时候才分叉。交接件的稀缺资源不是字数，是**下一棒的第一屏**；稳定层的正确位置是「一次写、每棒指」。而**删副本换指针**会把风险从「两处不一致」挪到「指针指错」—— 所以指针必须唯一可解析（A-10 正是踩在这里）。
- **反例**：**A-10**（副本换成指针之后，指针落到了**另一个实体**）；同族背景 = **A-06**（副本与原件不一致的一般形态：两处书写点只改被看见的那处）。
- **怎么查**：**半机械** —— 交接件**受容量门约束**（它落在 `capacityTiers` 的**默认档**，上限 / 行数 / 单行长度都按默认档判，真源 = `kit.config.json`），但**没有任何探针判「这段是不是副本」**：单册上限只扫 `principles/` 与 `anti-patterns/`，冷启动字节门只看 `coldStart.files` 那三件。人工三问：① 它在别的文件里有没有**全本**？② 改规则（角色 / 命令 / 环境 / 阈值）时要不要**回来改它**？③ 删掉它，下一棒还开得了工吗？——前两问答「是」且第三问答「能」→ 换成指针。机械辅助只有一条：`grep` 稳定层的名字与关键数字，命中的**第二处**就是副本。

## P-17 交接件里的「是什么」必须指回原件或给出判据


- **规则**：交接件里每个状态值 / 事实断言的合法形态**只有两种**：① **指针**（真源在哪：`VERSION` · `git tag --list` · 你的台账 §1）；② **判据**（下一棒自己算得出来的那一句，例：「`git tag --list` 未见它 = 上一棒收尾未完成」）。**禁止第三种**：**结论性事实**（「HEAD = 某哈希」「已收口」「余量还有」）与**期望值**（「应为 X」「≥ N」）。确需落数值时，必须带**命令 + 实测时间**，且受体在**P-10 ①** 管（最后一次编辑之后重测）。**与 P-13 的分工**：P-13 的断言给**机器**判（注入态 / 校验），本条的断言给**人**读（第一屏）。
- **为什么**：交接件**写于上一棒的计划里、读于下一棒的现状里**，中间隔着一整个收尾 —— 写「我会打这个 tag」的人在当时是对的，读的人拿到的却是一个**没有失效标记的断言**（A-11）。判据式写法的价值在这一点：它把「上一棒到底做完没有」变成**下一棒第一步就能算出来的事**，不依赖作者的记忆、也不依赖他的诚实。同理，转述的事实（DB 列名 / 路径 / 数量）在文本与原件之间**没有门禁兜底**（一次实测：两份活文档转述同一个错列名，一路继承）。
- **反例**：A-11。
- **怎么查**：**半机械** —— 探针 5 只查「路径存在」；「这句该写数值还是写判据」没有探针。人工：把交接件里每个「是 / 已 / 应为 / 还有 / 等于 / =」圈出来，逐个问「下一棒用**哪条命令**能自己得出这个答案」；答不出命令 → 它就不是判据，改成指针或补命令。转述类断言另加一问：「我在**本会话**里打开过原件吗？」

## P-18 必读清单必须可证伪


- **规则**：清单每一行都要能被下一棒**当场地**验真或证伪，四条同时：① **带「为什么」** —— 读者据此判断**该不该读、读哪节**；没有「为什么」的清单，读者只能全读或全不读；② **开工第一步逐行打开**，不是「有空再核」；③ **路径跨机可解析**：只指**已跟踪**锚点，本机抽屉出处必须显式标注「本机未跟踪」（否则换机 / 新克隆解析不到，而本机门禁全绿）；④ **跳过要写明**：明确不需要读的条目写清「本项不需要」，否则默认算漏读。**任何一行打不开 → 当下报缺口**（出口 = P-02 的 R3），**并且写进唯一留后登记面**（本方法仓 = 留后登记面 §5；只写在对话里 = 没登记），不许猜、不许绕、不许自创。
- **为什么**：清单是**写的人**自证的 —— 他写的时候文件在、在他机器上、节号是对的；而**读的人**第一次打开才知道它还在不在（A-12）。清单又是交接件里**唯一会被逐条执行**的部分：它错了不会让任何门禁变红，只会让下一棒在第一步撞墙 —— 而撞墙的最坏出口是「按『没找到 ≠ 不存在』自己造一条路」。
- **反例**：A-12。
- **怎么查**：**半机械** —— 机械点：探针 5（本方法仓 `.md` 路径死链）+ 探针 2（`P-`/`A-` 引用存在）；**节号是否存在、「为什么」列有没有、「本机未跟踪」标了没**没有探针。人工：开工第一步逐行打开前 20 行确认节号在 —— 这是本册唯一「开工前必须先做」的动作；打不开就停，先报缺口。

## P-19 验收 = 独立复跑；自评只作待验清单


- **规则**：回传报告里的每个数字都是**自评**，不是验收。验收动作只有两个：① **本会话自己跑一遍** —— 同一个脚本、同一组命令，取**这次**的判定行 + 退出码（判据 = P-11）；② 跑不了 / 不适用时，**明写「未复跑 + 原因 + 影响面」** —— 影响面要到「**哪几条结论因此没有证据、谁在什么时点补**」这一粒度（写「有一定影响」= 没写）。**不许**用「报告说绿了」「复核说是的」代替。理由是对象不同：自评是「我按我的理解做完了」，验收是「照规则它确实成立」。（**与 P-10 ② 的分工**：P-10 ② 管第二遍**怎么换判据**，本条管第一遍的数字**由谁跑**。）
- **为什么**：自评与验收在**成功时**几乎总是一致，在**失败时**才分叉 —— 而分叉的时刻正是唯一需要它们的时刻（A-07 ②：工具把 `2` 回传成 `1`，被当成真实退出码写进结论）。复跑的成本是秒级到分钟级，误信的成本是「红随提交进历史」，且**发现的人不知道自己丢了东西**。
- **反例**：A-07。
- **怎么查**：**半机械** —— 机械点 = 脚本**自己**的退出码 + 判定行明细（P-11）；「这个数字是谁的命令」没有探针。人工：对着报告每个数字问「它出现在**本会话**的哪一次运行里」；答不出 → 现在跑。旁证：静态推论尤其要跑（没跑之前它只是假设）。

## P-20 复核：一棒一次、边界由派发方给定、回传只作反例清单


- **规则**：**派几次 / 什么时点派**（D10 **已裁 2026-10-31**）：一棒**一次**，放在**全部写回之后、commit 之前**；**轻档可跳，但要写理由**（档位 = 收尾清单第 1 步）。判据不是「按工作日历排」，而是**那一刻已经落盘了什么** —— 写回面（handoff / 地图 / 状态行 / CHANGELOG / 台账）还没落盘时做的复核，**不得宣称覆盖了发版面**。**为什么只一次**：复核反例里的**机械类（节号 / 指针 / 数字 / 文本比对）是主会话自己的活**（`P-10 ④`）—— 2026-10-31 实测两轮 26 条里 **16 条属机械类**（A 11/16 · B 5/10），即两轮里真正需要「另一个 LLM」的只有语义那一半；把它们一并外包，等于用复核的成本补自查的洞。**派发件里必须有两条**：① **只读** —— 不改任何文件（含「不要为了验证而写临时文件」）；② **边界** —— 哪几类**必须**查、哪几类**明确不查**（不给边界，回传查的就是它自己挑的那几类）。回传后按两条处置：① 它是**反例清单，不是判决** —— 每条**当场复算**再决定收不收；② **结论要带形态** —— 「跑出来的」与「看出来的」不是一种证据，静态推论必须标「未跑」，未跑的部分照录进未覆盖。**产出形态的其余口径**（只找反例 / 覆盖范围 / 假阳性单列 / 机械类占比 = 自查失职）**判据 = P-10 ②④**，本条不复述。
- **为什么**：复核的价值全在**换判据**（P-10 ②）。而它的产物一旦被当判决，主会话就绕开了自己的验收（P-19 失效）；它的**静态推论**一旦被当实测，一个未验证的结论就被**升级成了证据**（本方法仓实测：一条「隔离不成立」原是静态追踪，实跑后才敢写进册）；它挑的那几类一旦被当全集，没查的部分就**默认成了没问题**。
- **反例**：A-09（同型：证明只做过一次、没留形态 → 复核也就成了一次性观测）。
- **怎么查**：**半机械** —— 无探针。人工：派之前先答一句「**四类机械自查（节号 / 探针面 / 数字 / 文本比对）做完了吗**」（没做完不许派），再答一句「**用户授权收尾了吗 / 写回面五件落盘了吗**」（判据 = 收尾清单第 1 步的派发前置；缺一不许派，提前派只能叫预检且不得宣称覆盖发版面），拿到回传再答三句「它**跑**了吗 / 哪几类**没查** / 有几条是我自己的机械自查该挡的」，四个答案写进汇报（覆盖范围 0 条也要写「查了哪几类」）。
