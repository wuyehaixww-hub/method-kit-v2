# L0 原则 · 08 采纳（把一套方法搬进别人的项目）

> 本册 = 「采纳」的**判断标准**：做完了凭什么算数，做砸了长什么样。3 条：P-27..P-29。
> 与邻近册的分工：**动作协议** = `skills/adopt-kit`（装）· `skills/extract-kit`（取）；**本册** = 判断（不教怎么做，教怎么算成）。
> 每条四段：**规则** / **为什么** / **反例** / **怎么查**；`怎么查` 没有机械点就诚实写「半机械」。
> **「规则」段末尾必须带「不适用」** —— 判据的边界和判据本身一样重要（2026-11-01 盲测抓出：只写「什么时候该用」不够）。

## P-27 验收只在被采纳方的仓里跑，并点名被量的对象


- **规则**：任何「装完了 / 采纳成功」的结论，必须同时满足两条 —— ① **在被采纳方的仓里**跑 ② **判定行点名被量的对象**。缺一条 = 没验收。三条禁令：**不得拿别处的绿当这里的绿**；**不得只读数字不读「配置 = …」那一行**；**不得在夹具 / 副本里验收后搬到真仓**。**不适用**：目标仓**一个可跑的门禁都没有**时（绿地刚开工）—— 降级为「口头点名」：说清你验的是什么、在哪验的，并写「未验」。**「可跑」= 此刻能在这里执行并读出判定行**；门禁存在但跑不了（无执行权限 / 仓只读 / 要凭证或联网 / 单次要跑几十分钟）**按「没有可跑的门禁」处理** —— 两种情况结果同形（真仓没被量到）。一旦能跑了，回到本条。
- **为什么**：门禁的结论只对「它量的那个对象」成立。对象错了，判定行、数字、退出码**全都对**，唯独你要验的那件事没发生 —— 而这种失败**不报警**，绿读得很自然。
- **反例**：A-16（门的结论没错，门判的不是那件事）。
- **怎么查**：**半机械** —— 跑前先看判定行第一行是否写着你**脚下这个仓**的路径；脚本侧已有护栏（不带 `--root` 且 cwd 不在该仓 → `exit 2`，2026-11-01 落）。

## P-28 协议只写意图、不写判据 → 执行者会按自己的判断改


- **规则**：给别人的动作必须写成「**照做会得到什么**」，不能写成「我的意思是…」。判据 = **执行者是否需要自己决定**（抄还是并、留几条、引不引结构名）。需要自己决定 = **协议缺口**，不是执行者的错。两个方向都要写：**多带** → 裁到 0 处（`P-26`）；**少带 / 变形** → 逐条比对模板，分四类点数：**原样 / 改造（写明改了什么）/ 新增 / 丢失** —— **丢失 ≠ 0 且没写理由 = 不合格**（「条数相等」不够：D-4 就是丢了 2 条又新增 2 条，终态仍是 5 条）。**不适用**：① 执行者就是作者本人、且只做一次（没有「下一次」也没有「别人」）。② **探索期**：判据 = 能不能一句话说出「这次要产出什么」；说不出 = 探索期。**探索期不是豁免** —— 它恰好是「执行者必须自己决定」最多的时刻，所以只降到最小判据：**「哪些必须原样带走」+「条数必须相等」仍要写**。**用了 ① / ② 必须留一行痕**（哪次、为什么豁免）：不留痕 = 事后看不出豁免发生过，那正是本条要治的「悄悄丢东西」。
- **为什么**：执行者不是在读你的意图，是在**做决定**；协议不给判据，它就用自己的。结果只有两种：**越权救回来**（运气，且下一次不一定）或**悄悄丢东西**（损失，且没人发现）。两种都不报错。
- **反例**：A-17（照字面 copy = 死指针）。**第二个实例**（同根因，不另立条，`A-14`）：D-4 常驻约束 5 条被重裁丢 2 条 —— 「copy 件没有可验证的完成判据」这一句能同时解释多带与少带。
- **怎么查**：**半机械** —— 写完协议自问「执行者要自己判断几次」；>0 就补判据。机械侧只能查「照做会不会带进目标仓没有的行」（`trim-scan` 的死指针面）。

## P-29 采纳记录里的来源 / 路径必须「明天还打得开」，否则写「未落地」


- **规则**：记录里的「来源 / 依据 / 位置」只写两种 —— ① **稳定的**（进版本库的路径 / URL / 可查 ID）② **明确标「未落地」**。临时目录、本机绝对路径、会被清理的副本 = **未落地**。**不适用**：明确的一次性记录（当轮用完即弃、不进版本库、不打算给别人看）—— 但要在记录里标「一次性」；**来源本身合法但不稳定**（如一次线上会话）不属豁免，仍要标「未落地」。**一旦这条记录要进版本库、要给第二个人看，回到本条**（补稳定来源，或补「未落地」）。
- **为什么**：采纳记录的作用是「三个月后还能顺着它找回现场」。指不回去的路径不是记录，是**填空**；而它看起来是填满的 —— 所以不会有人发现，直到有人真的去点。
- **反例**：A-18（自己写下的理由，没有用在自己的记录上）。
- **怎么查**：**没有机械点** —— 写路径前问「三个月后它还在吗」。注意：`trim-scan` **抓不到**本条 —— 它跳过盘符 / `…` 占位 / `%TEMP%` 这类 token（`kit/scripts/trim-scan.mjs` 的 `fileish()`），而 A-18 的写法恰好全在跳过面内；别把「跑过一次 trim-scan 是绿的」当成本条通过（`P-15`：机械点只判形态）。
